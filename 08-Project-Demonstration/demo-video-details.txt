2. Problem Statement
3. Open ServiceNow
4. Show Flow Designer

7. Show Standard Laptop Process Engine configuration
8. Order the laptop
9. Show the request
10. Approve the request
11. Show Requested Item
12. Show Catalog Task
13. Explain automation
14. Final result
15. Closing
